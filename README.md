# ALX System Engineering DevOps

## Shell Scripts

### 0x03-shell_variables_expansions

1. **0-alias** - Creates an alias named 'ls' with value 'rm *'
   - Run: `source 0-alias`

2. **1-hello_you** - Prints "hello" followed by the current user name
   - Run: `./1-hello_you`

3. **2-path** - Adds /action to the PATH environment variable
   - Run: `source 2-path`

4. **3-paths** - Counts the number of directories in the PATH variable
   - Run: `./3-paths`

5. **4-global_variables** - Lists all environment variables
   - Run: `./4-global_variables`

6. **5-local_variables** - Lists all local and environment variables and functions
   - Run: `./5-local_variables`

7. **6-create_local_variable** - Creates a local variable BEST with value "School"
   - Run: `source 6-create_local_variable`

8. **7-create_global_variable** - Creates a global variable BEST with value "School"
   - Run: `source 7-create_global_variable`

9. **8-true_knowledge** - Prints the result of adding 128 to TRUEKNOWLEDGE variable
   - Run: `./8-true_knowledge`

10. **9-divide_and_rule** - Divides POWER by DIVIDE variables
    - Run: `./9-divide_and_rule`

11. **10-love_exponent_breath** - Displays BREATH to the power of LOVE
    - Run: `./10-love_exponent_breath`

12. **11-binary_to_decimal** - Converts binary number in BINARY variable to decimal
    - Run: `./11-binary_to_decimal`

13. **12-combinations** - Prints all possible two-letter combinations except "oo"
    - Run: `./12-combinations`

14. **13-print_float** - Prints NUM variable with two decimal places
    - Run: `./13-print_float`

15. **100-decimal_to_hexadecimal** - Converts DECIMAL variable to hexadecimal
    - Run: `./100-decimal_to_hexadecimal`

16. **101-rot13** - Encodes and decodes text using ROT13 cipher
    - Run: `./101-rot13`

17. **102-odd** - Prints every other line from input, starting with the first
    - Run: `./102-odd`

18. **103-water_and_stir** - Adds WATER and STIR variables in custom base systems
    - Run: `./103-water_and_stir`
